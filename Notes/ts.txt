tsconfig used for 
	automated compiling
	same ts setting in the team 
	catch error in compile time and not runtime
	better proj structure
	better performance
	watch mode
	module type and js version control 
	
	
tsconfig file has 
		compileroption ;- how and what to compile 
		files ;- define which file to compile using "tsc" command 
		extends ;- inherit setting from other config files,,first it will load the base file and then whatever is inherited will override the specific setting,, files,inclue,exclude will replace the files from the base file 
		include,exclude ;- pattern of files to either include or exclude in compiling
		refrences ;- helps to organize large projects , split large codebase into smaller , composite should be true
		target ;- for js version
		removecomments ;- as name say
		nounusedparamaters ;- error for unused or extra params
		nounusedlocals ;- error for unused local var
		outdir ;- placed where the compiled js will be saved
		rootdir ;- only files in rootdir will be compiled
