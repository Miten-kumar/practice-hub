• JWT token structure and security
    A JSON Web Token (JWT) is a compact, URL-safe token used for securely transmitting information between parties. It is commonly used for:
        Authentication (login sessions)
        Authorization (access control)
        Information exchange between services (APIs, microservices)
https://www.jwt.io/introduction#when-to-use-json-web-tokens
https://curity.io/resources/learn/jwt-best-practices/

The rule of thumb is — the service that receives a JWT should always validate it.
Always Check the JWT Issuer
