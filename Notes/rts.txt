Premature optimization with useMemo/useCallback
		Code Complexity & Readability: Wrapping every value or function in useMemo or useCallback adds boilerplate code and an extra 							 layer of complexity, making the code harder to read, write, refactor, and maintain.
		Performance Overhead: Memoization is not free; the hooks themselves have a small execution and memory overhead for caching and comparing dependency arrays. For simple calculations or small applications, this overhead can sometimes outweigh the benefits of avoiding a re-computation or re-render.
		Potential for Bugs: Incorrectly managing the dependency arrays can lead to "stale" values or functions, introducing subtle and hard-to-debug bugs into the application.
		Misguided Effort: React is optimized by default for performance in most scenarios. Developers should focus on clean, functional code first. Optimizing parts of the code that aren't performance bottlenecks is a waste of effort.

Conditional hooks - rules of hooks violations
		Inside Conditions: Never use if or && statements around hooks.
		Inside Loops: Do not call hooks within for or while loops.
		After Conditional Returns: Never place hooks after an if (...) return ... statement.
		In Event Handlers/Callbacks: Hooks cannot be called inside nested functions or event handlers.
		Inside try/catch/finally: Hooks cannot be inside exception handling blocks.

useReducer vs useState - complexity threshold
		usestate ;- less or simple state management
		usereducer ;- more and complex state management 
		
		
		Feature 	useState							useReducer
		Complexity	Simple and straightforward					More complex, suitable for intricate state transitions
		Use Case	Ideal for independent state updates (boolean, string, number)	Suitable for managing complex state objects, arrays, and transitions based on previous state
		Logic Location	Logic is within the component or event handlers			Logic is centralized in a pure reducer function (often outside the component)
		Boilerplate	Minimal								More verbose (requires actions and a reducer function)
		Performance	Good for simple scenarios					Can optimize performance for complex state by preventing unnecessary re-renders
